Kotlin Script

Creates a Kotlin/JVM project with a src/main/kotlin/main.kts script that can be opened and edited with Kotlin syntax highlighting.

Choose the build system (Gradle Kotlin DSL, Gradle Groovy DSL or Maven), enter the project name, location and artifact coordinates, and the wizard creates a ready to open project with a Kotlin 2.3.21 build file. Gradle projects include a Gradle wrapper.

Note: the generated build files do not compile or run .kts scripts; the script is edited and executed as a standalone Kotlin script.
